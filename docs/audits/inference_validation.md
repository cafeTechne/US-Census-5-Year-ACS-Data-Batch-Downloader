## Findings

Every gated method is inside the acceptance band.

Interpretation notes:
- `fit_replicate` `se_total = sqrt(se_model^2 + se_sampling^2)` (decision 2) double-counts outcome sampling error for a superpopulation target, because the model residual variance already absorbs it; over-coverage there is expected (conservative). `se_sampling` alone is the design-based SE for the finite-population (census-of-areas) coefficient.
- `fit_replicate` does not correct covariate measurement error (noisy-covariate row): use `regression_calibration` or `simex` for that.
- Correlations among ACS estimates are attenuated by sampling error: Fisher-z intervals cover the correlation of the observed estimates, not of the true values.
